# Anima Tec — presentación web

Presentación en HTML de la premisa, el logline, el storyline, la unidad de acción dramática y el framework del corto del Proyecto Anima Tec (Creación Digital 4, con Arte Dramático).

Navegación: flechas del teclado, rueda del mouse, clic en los costados de la ventana o deslizar en el móvil.
